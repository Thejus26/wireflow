# Getting Support

Thanks for using Wireflow! Here's where to go depending on what you need.

## Questions and usage help

1. Check the [README](README.md) for setup instructions, the component definition format, and the roadmap.
2. Search [existing issues](https://github.com/Thejus26/wireflow/issues?q=is%3Aissue) — your question may already be answered.
3. If you're still stuck, [open an issue](https://github.com/Thejus26/wireflow/issues/new/choose) and start the title with `[Question]`. Include what you were trying to do, what you expected, and what happened, plus a sample chip/netlist definition if relevant.

## Bugs

Please use the **Bug report** form on the [issue chooser](https://github.com/Thejus26/wireflow/issues/new/choose). Reproduction steps and your environment (OS, browser, Node version, commit) make a fix much faster.

## Feature and component requests

Use the **Feature request** or **Component / footprint request** forms on the [issue chooser](https://github.com/Thejus26/wireflow/issues/new/choose).

## Security vulnerabilities

**Do not use public issues.** Follow [SECURITY.md](SECURITY.md) to report privately.

## Code of Conduct concerns

See the Enforcement section of the [Code of Conduct](CODE_OF_CONDUCT.md).

## Contributing

Want to fix something yourself? Read the [Contributing Guide](CONTRIBUTING.md).

---

Wireflow is maintained in spare time, so replies may take a few days. Thanks for your patience!
